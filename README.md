# Traditional Chinese Medicine × Integrated Care

Interactive presentation website for the integrated-care vision of
พจ. กมลทิพย์ เผ่าอำนาจฤทธิ์. Built with Next.js and ready for Vercel.

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

This starter does not use `wrangler.jsonc`.

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: create a production build
- `npm start`: serve the production build

## Deploy on Vercel

Import this GitHub repository into Vercel. Vercel will detect Next.js and use
`npm run build` automatically; no environment variables are required.
